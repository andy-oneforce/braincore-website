This is the first post on the rebuilt ASIOS site. The blog exists to cover how the site itself gets built, one small decision at a time.

The site runs on a hand-rolled build engine — markdown in, static HTML out — built specifically for this project rather than adopted from an existing static-site framework. Expect posts here to track that build as it grows: new templates, new tooling, and the occasional bug report that changed a decision.

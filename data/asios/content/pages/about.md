ASIOS runs on a layer model: **Platform, Brand, Account, Server, System, Support, App, User, Import,
and Export**, in a fixed authority order. Each layer declares who may change it and where it ships —
the boundary that used to be redrawn by hand, file by file, is now one rule plus a container
whitelist.

Every idea starts as a conversation and becomes an activity in the same motion — worked in place,
its history kept turn by turn, nothing left dangling. That conversation runtime is what built this
website: the content on these pages, the templates that render it, and the checks that verify it
were all produced by activities running inside ASIOS.

Today there is one Workspace — the Creator's. The platform is built to install more.
